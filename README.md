# Sales Analytics Dashboard

## 📊 Project Overview
This project analyzes retail sales data to identify trends, patterns, and business insights.

## 🛠 Tools Used
- Python (Pandas, NumPy)
- Power BI
- Excel

## 📈 Key Insights
- West region generated the highest sales
- Technology category is the most profitable
- Sales peak during November and December

## 📊 Dashboard Features
- KPI cards for total sales and profit
- Sales by region visualization
- Monthly sales trend analysis
- Interactive slicers for category filtering

## 📁 Files Included
- sales_analysis.ipynb
- cleaned_superstore.csv
- sales_dashboard.pbix

## 🎯 Objective
To perform data analysis and create an interactive dashboard for data-driven decision making.
